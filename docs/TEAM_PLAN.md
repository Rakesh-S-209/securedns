# One-week team plan

## Member 1 — DNS and incident analyst
Deliver: DNS record lookup module, resolver comparison, local simulation review, Wireshark screenshots, case-study timeline and attack-chain report section.
Learn: DNS A/AAAA/MX/NS, DHCP role, UDP/53, transaction IDs, DNS spoofing, packet capture.

## Member 2 — DNSSEC and DoH engineer
Deliver: DNSSEC/DoH module, tests against signed and unsigned domains, explanation of AD bit and DoH limitations.
Learn: DNSKEY, DS, RRSIG, trust chain, validating resolver, DoH vs DNSSEC.

## Member 3 — TLS engineer
Deliver: TLS certificate analyzer, tests against valid and invalid test certificates, screenshots of certificate details.
Learn: CA, X.509, hostname verification, TLS handshake, certificate expiry, authenticated encryption.

## Member 4 — Integrator and QA lead
Deliver: Streamlit integration, requirements, GitHub repository, test log, final report assembly and PPT.
Learn: module interfaces, Streamlit, Python environments, test evidence, architecture and limitations.

## Daily milestones
Day 1: Everyone installs project; confirm modules run.
Day 2: DNS and TLS baseline modules working.
Day 3: DNSSEC/DoH validation and local simulation.
Day 4: Integration and UI polish.
Day 5: Test matrix, screenshots, packet captures.
Day 6: Report and presentation complete.
Day 7: Rehearsal, bug fixes, final packaging.

## Definition of done
- App starts on a clean environment.
- All modules return understandable results or safe errors.
- Automated tests pass.
- Screenshots and test log are saved.
- Report claims match observed evidence.
- Every team member can explain the full architecture and their own module.
